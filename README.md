### 🧰 Highlighted Project

#### 🔹 [`smartstepper`](https://github.com/Miladxsar23/smartstepper)
> A composable, orchestration-first, validation-aware multi-step form engine for React.

- ✅ Supports both `yup` and `zod` schemas
- ⚙️ Handles orchestration, validation, and UI layers
- 🔁 Easy navigation and step control
- 💡 Built for real-world forms

🔗 [Docs](https://miladxsar23.github.io/smartstepper-docs) · [Demo](https://codesandbox.io/p/sandbox/g8g8c7) · [Medium article](https://medium.com/@miladxsar23/smartstepper-v2)
